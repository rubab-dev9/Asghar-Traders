# Asghar Traders & Wholesale

A modern, responsive business website for **Asghar Traders & Wholesale**, a wholesale grocery business based in Old City, Bahawalpur, Pakistan.

The website is designed to help wholesale buyers and retailers explore grocery product categories and easily contact the business for product inquiries and wholesale details.

## Features

- Responsive design for desktop, tablet, and mobile devices
- Modern business landing page
- Home page with hero section and business highlights

- Products page with product categories
- Product search functionality

## Pages

### Home

The homepage introduces Asghar Traders & Wholesale and provides an overview of the business, product categories, and key information.

The About page provides information about the business, its wholesale focus, customer approach, and the grocery categories it serves.

### Products

The Products page displays available grocery categories and includes:

- Product search
- Category filtering
- Product cards
- Product descriptions
- WhatsApp inquiry buttons

### Contact

The Contact page allows visitors to:

- View business contact information
- View the business location
- Contact the business through WhatsApp
- Submit a product or wholesale inquiry
- Open the business location in Google Maps

## Installation

Clone the repository:

```bash
git clone https://github.com/rubab-dev9/Asghar-Traders.git
```

Navigate to the project directory:

```bash
cd Asghar-Traders
```

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```

The application will be available at the local development URL provided by Vite.

---

## Build for Production

To create a production build:

```bash
npm run build
```

To preview the production build locally:

```bash
npm run preview
```

## Contact & Inquiry

The website provides direct WhatsApp communication for wholesale product inquiries.

Visitors can select a product and use the **"Inquire on WhatsApp"** option to contact the business directly.

The contact page also provides the business phone number, location, and Google Maps direction.

---

## Responsive Design

The website is designed to work across different screen sizes:

* Desktop
* Laptop
* Tablet
* Mobile

Tailwind CSS responsive utilities are used throughout the project to provide a consistent experience across devices.

---

## Animations

ScrollReveal is used to provide scroll-based animations throughout the website.

Elements are revealed as the user scrolls through different sections, creating a smoother and more engaging browsing experience without changing the core functionality of the website.
